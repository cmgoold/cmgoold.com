Hi, I'm Conor. This is my small slice of the internet to write about statistics, software engineering, science, books, and a smattering of more informal topics too.

I live in North East England, working remotely as a data scientist. This site started in early 2025 as an informal New Year Resolution to practice writing and learn more web development. I was inspired by reading many great independent blogs and websites following the IndieWeb movement, as well as those using platforms such as Bear Blog, Pika and others.

This site is free of AI-generated content and advertising. I don't track any of your personal data or activity.

All the code for this website be found at its Github repository. If you have comments, open an issue on Github, or email me at cmgoold.blog@proton.me.
